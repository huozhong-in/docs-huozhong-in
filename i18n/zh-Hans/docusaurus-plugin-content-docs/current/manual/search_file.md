# 通过关键字搜索文件

主界面中间区域上方是文件列表区，您可以根据关键字进行全路径搜索，也就是既可以是文件名也可以是文件所在文件夹名。注意，不支持根据文件内容搜索。

:::tip
能搜索到的文件类型扩展名配置在[文件识别规则](/docs/manual/configuration)
:::

![主动搜索文件](/img/search_file01.png)

1. cmd+k快速定位到搜索栏，输入路径关键字，回车搜索。
2. 文件出现在列表中，可直接打开Finder定位到文件位置。

## 文件列表浮动菜单

文件列表上对于不同类型的文件有不同的鼠标浮动菜单

- 图片问答，支持 `["png", "jpg", "jpeg", "gif", "webp"]`格式

- 固定文件，支持`['pdf', 'docx', 'pptx', 'txt', 'md', 'markdown']`格式文档

> pin操作的目的是让改文件跟当前对话/会话建立关联，同时开始分析文件内容建立知识索引，详见[多模态检索](/docs/manual/pin_file)

- 共读模式，暂时PDF独有，详见[共读模式](/docs/manual/co_reading)
