# 共读模式(alpha)

:::tip
共读模式现只支持PDF文件，调用系统预安装的“预览.app”打开。
:::

共读模式是更深度的“同文件对话”，启动共读模式后窗口将左右分屏，PDF阅读器在右侧。每当你询问AI时，它会先把PDF阅读器当前界面截一张图，也就是跟你共享视野，这样即使图片、表格上下文也能充分给与，帮助它更好的合成答案。

![AI与你共读PDF](/img/co_reading01.png)

- 进入共读模式后会随时检查PDF阅读器窗口的情况，被遮挡或最小化都会有相应处理逻辑，保障共读体验。
- 在模式生效期间如果PDF阅读窗口被最小化会显示提示，提醒用户是否需要退出共读模式。
- 在模式生效期间如果PDF阅读窗口被其他窗口遮挡，在问答截图时会自动把其窗口拉到最前。

:::warning
- 共享阅读进度和视野需要“屏幕录制”权限
:::
