# 按标签搜索文件

应用侧边栏的左上角是文件标签云，这些标签是通过自动解析文件内容而生成的，帮助用户发现沉寂多年的文件。

因为解析文件内容比较耗时，每次成功打标签之后都会更新界面，也能看到“已打标签文件数/所有可解析文件数”整体进度。

- 用户点击标签后，打过这个标签的文件们将会出现在文件列表区，跟搜索功能共享一个结果区。
- 能被解析和打标签的文件类型，扩展名有['pdf', 'pptx', 'docx', 'xlsx', 'xls', 'md', 'markdown', 'txt'] 。
- 技术上支持多标签聚合，也就是通过多个标签联合搜索的方式缩小文件范围，现有产品设计没提供此功能，如您有好想法记得告知我们。
