# 产品功能和特点

KnowledgeFocus是macOS桌面应用，隐私优先是它的第一设计原则，它能充分发挥原生应用在访问本机文件系统和利用本机算力的优势。

## 产品功能

- KF是搜索本机文件的离线搜索工具。它通过扫描本机文件建立索引，并在后续监控文件变动时立即更新索引。
- KF是本机知识文件的主动推荐工具。通过自动解析和读取摘要文件内容，高速给文件打语义标签，帮助用户重新发现沉睡在硬盘深处的历史文件。
- 和你的文件聊天。不需要上传，经过预处理后即能针对文件知识问答，更进一步的“共读模式”中AI能观察你的阅读进度和视野，结合外部数据工具进行答案合成，实现独特的共读体验。

## 产品特点

- KF是本机文件知识发现和数据工作台，以数据隐私为第一优先级，完全离线方式帮助知识工作者发现、归集和利用这些知识，在AI时代不断积累和强化数据价值。
- KF内置视觉小模型，可以不联网的情况下实现很多数据的处理和知识问答，压榨本地算力价值，回收硬件沉默成本。
- KF是桌面智能体平台，是下一代RPA载体，拥有观察和控制两类能力，在取得OS授权后可以操控整个计算机，拥有无限可能。
- KF代码完全开源，使用主流技术栈`Tauri/Rust + React/TypeScript/Vite/Bun + Python/PydanticAI + TailwindCSS + Shadcn/Tweakcn + Vercel AI SDK v5/AI Elements + SQLite + LanceDB`实现优秀的产品体验。欢迎fork和PR
