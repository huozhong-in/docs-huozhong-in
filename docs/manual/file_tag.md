# Search Files by Tag

The file tag cloud is located in the upper left corner of the app sidebar. These tags are automatically generated by parsing file content, helping you rediscover files that have been dormant for years.

Because parsing file content is time-consuming, the interface updates after each successful tagging operation, displaying overall progress as "Tagged Files / Total Parsable Files".

- When you click on a tag, files tagged with that label will appear in the file list area, sharing the same results area as the search function.

- File types that can be parsed and tagged include the following extensions: `['pdf', 'pptx', 'docx', 'xlsx', 'xls', 'md', 'markdown', 'txt']`.

- Multi-tag aggregation is technically supported, meaning you can narrow down the file range by combining multiple tags for searching. This feature is not currently available in the product design, but we'd love to hear your ideas if you have suggestions.
