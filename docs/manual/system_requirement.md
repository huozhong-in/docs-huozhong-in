# System Requirements

- KF is a macOS application and does not support Windows or Linux. There are currently no plans to support iOS or Android.

- KF requires macOS High Sierra (10.13) or later. [How to check your macOS version](https://support.apple.com/en-us/109033)

- KF has computing power requirements and only supports Apple M-series chips. It does not support Intel chips. Smooth operation requires an M2 or higher chip and at least 16GB of RAM.
