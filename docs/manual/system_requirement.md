# System Requirements

- KF is a macOS-only application and does not support Windows or Linux. There are currently no plans to support iOS or Android.

- KF requires macOS High Sierra (10.13) or later. [How to check your macOS version](https://support.apple.com/en-us/109033)

- KF has specific hardware requirements: it only supports Apple M-series chips and does not support Intel-based Macs. For optimal performance, an M2 chip or newer with at least 16GB of RAM is recommended.
